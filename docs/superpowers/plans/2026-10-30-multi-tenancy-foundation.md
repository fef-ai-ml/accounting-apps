# Multi-tenancy Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Isolate every tenant's data in the shared Postgres database, with the tenant taken only from the Keycloak access token.

**Architecture:** The authentication converter resolves the token's Keycloak organization alias to a tenant UUID once
per request (through the `TenantDirectory` interface, implemented by `iam`) and carries it on a `KeycloakAuthentication`.
A new `backend/tenancy` module feeds that UUID to Hibernate (`@TenantId` filtering) and to Postgres
(`set_config('app.tenant_id', …)` per pooled connection, enforced by Row-Level Security). The API runs as a new
non-owner role `app_runtime`, so RLS always applies; Flyway runs as the owner.

**Tech Stack:** Spring Boot 4.1.2, Spring Security 7.1.2, Hibernate 7 (via `spring-boot-starter-data-jpa`), HikariCP,
PostgreSQL 17, Flyway, Caffeine, Keycloak 26.8.1 Organizations, ZK 10.3, Testcontainers, Java 25.

**Spec:** `docs/superpowers/specs/2026-10-29-multi-tenancy-foundation-design.md`

## Global Constraints

- Tenant id = Keycloak organization id (UUID), column `tenant_id UUID NOT NULL`; never generated by us.
- The tenant comes only from the access token's `organization` claim (list of aliases); exactly one entry, else no tenant.
- Demo tenant `demo` = `7f3a0c4e-1b2d-4e5f-8a9b-0c1d2e3f4a5b`; second tenant `acme` = `b2c4e6a8-0d1f-4a3b-9c5d-7e8f9a0b1c2d`.
- RLS predicate everywhere: `tenant_id = nullif(current_setting('app.tenant_id', true), '')::uuid`, in both `USING` and `WITH CHECK`.
- Runtime DB role `app_runtime` (`LOGIN NOSUPERUSER NOBYPASSRLS`, owns nothing, dev password `app_runtime`); Flyway runs as `app`.
- Flyway versions are global across module folders: this plan uses `V20261030_1` (iam) and `V20261030_2` (task).
- Modules are entered through one `*Module` class and composed with `@Import`; no cross-module package scanning, no cross-schema foreign keys; modules never import `iam`.
- Never declare a `clientScopes` array in `infra/keycloak/zk-spring-realm.json` (Keycloak then drops its built-in scopes).
- Code style: tabs, existing import grouping, Javadoc only where it explains why; tests use AssertJ and MockMvc like the existing ones.
- Backend tests need Docker (Testcontainers). On the maintainer's Mac: the three home-lab SSH tunnels up and `TESTCONTAINERS_HOST_OVERRIDE=home-lab`, `TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/run/user/1000/podman/podman.sock` set (already set as fish universal variables).
- Run module tests with `./mvnw -q -pl <module> -am test`; the whole build with `./mvnw verify`.
- Commits: explicit paths only (never `.bloop`/`.metals`); messages end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A pooled connection reset to `app.tenant_id = ''` must yield zero rows, not `invalid input syntax for type uuid` — pinned by `pooledConnectionForgetsTheTenant` (Task 2, pool size 1).
2. Resolving the tenant must not recurse into Hibernate (tenant lookup → repository → session → tenant lookup) — pinned by the real-token end-to-end tests in Task 5, which run `DbTenantDirectory` through the converter.
3. An authentication that is not a `KeycloakAuthentication` (e.g. a plain `JwtAuthenticationToken`) must see no tenant data instead of all of it — pinned by `plainJwtAuthenticationSeesNothing` (Task 2).
4. A write without a tenant must fail loudly rather than store a row with the root marker — pinned by `insertWithoutTenantIsRejected` (Task 2).
5. Hibernate schema validation running as `app_runtime` must still find the tables (grants present) — pinned by every Testcontainers test running as `app_runtime` with `ddl-auto=validate` (Tasks 2–5).

`KeycloakTenant.java`:

```java
package com.example.security;

import java.util.Collection;
import java.util.List;
import java.util.Map;
import java.util.Optional;

import org.springframework.security.oauth2.jwt.Jwt;

/** Reads the tenant's Keycloak organization alias from an access token. */
public final class KeycloakTenant {

	private KeycloakTenant() {
	}

	/**
	 * The single organization alias in the {@code organization} claim. Keycloak writes a list of aliases by default and
	 * an object keyed by alias when the mapper adds ids. No claim, several organizations or any other shape mean "no
	 * tenant": a user belongs to exactly one tenant.
	 */
	public static Optional<String> alias(Jwt jwt) {
		Collection<?> aliases = switch (jwt.getClaims().get("organization")) {
			case Collection<?> list -> list;
			case Map<?, ?> map -> map.keySet();
			case null, default -> List.of();
		};
		return aliases.size() == 1 && aliases.iterator().next() instanceof String alias && !alias.isBlank()
				? Optional.of(alias)
				: Optional.empty();
	}

}
```

`TenantDirectory.java`:

```java
package com.example.security;

import java.util.Optional;
import java.util.UUID;

/**
 * Translates a Keycloak organization alias into the tenant id (the organization's UUID) of an active tenant. The
 * {@code iam} module implements it; aliases are a safe key because Keycloak does not allow renaming them.
 */
public interface TenantDirectory {

	/** The tenant id, or empty when the alias is unknown or the tenant is not active. */
	Optional<UUID> tenantIdOf(String alias);

	/** Knows no tenant; used when a deployment has no directory, so a misconfiguration fails closed. */
	static TenantDirectory none() {
		return alias -> Optional.empty();
	}

}
```

`KeycloakAuthentication.java`:

```java
package com.example.security;

import java.util.Collection;
import java.util.Optional;
import java.util.UUID;

import org.springframework.security.core.GrantedAuthority;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationToken;

/**
 * A validated Keycloak access token with the tenant it was resolved to once, at authentication time. Data access
 * reads the tenant from here instead of looking it up again (a lookup would itself need a tenant).
 */
public class KeycloakAuthentication extends JwtAuthenticationToken {

	private final UUID tenantId;

	public KeycloakAuthentication(Jwt jwt, Collection<? extends GrantedAuthority> authorities, String name,
			UUID tenantId) {
		super(jwt, authorities, name);
		this.tenantId = tenantId;
	}

	/** Empty when the token names no organization, several, an unknown one or a suspended one. */
	public Optional<UUID> getTenantId() {
		return Optional.ofNullable(tenantId);
	}

}
```

`KeycloakJwtAuthenticationConverter.java` — replace the class body:

```java
public class KeycloakJwtAuthenticationConverter implements Converter<Jwt, AbstractAuthenticationToken> {

	private final PermissionResolver permissionResolver;

	private final TenantDirectory tenantDirectory;

	public KeycloakJwtAuthenticationConverter(PermissionResolver permissionResolver, TenantDirectory tenantDirectory) {
		this.permissionResolver = permissionResolver;
		this.tenantDirectory = tenantDirectory;
	}

	@Override
	public AbstractAuthenticationToken convert(Jwt jwt) {
		List<GrantedAuthority> authorities = permissionResolver.permissionsFor(jwt).stream()
				.sorted()
				.<GrantedAuthority>map(SimpleGrantedAuthority::new)
				.toList();
		String username = jwt.getClaimAsString("preferred_username");
		UUID tenantId = KeycloakTenant.alias(jwt).flatMap(tenantDirectory::tenantIdOf).orElse(null);
		return new KeycloakAuthentication(jwt, authorities, username != null ? username : jwt.getSubject(), tenantId);
	}

}
```

```java
package com.example.tenancy;

import java.util.List;
import java.util.UUID;
import java.util.function.Supplier;

import jakarta.persistence.EntityManager;
import jakarta.persistence.PersistenceContext;

import org.junit.jupiter.api.AfterEach;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.SpringBootConfiguration;
import org.springframework.boot.autoconfigure.EnableAutoConfiguration;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.context.annotation.Import;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationToken;
import org.springframework.transaction.support.TransactionTemplate;

import com.example.security.KeycloakAuthentication;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

// One pooled connection, so consecutive transactions reuse it: a tenant left on it would leak.
@SpringBootTest(classes = TenancyTests.TestApp.class,
		properties = { "spring.security.oauth2.resourceserver.jwt.issuer-uri=http://localhost:9/realms/test",
				"spring.datasource.hikari.maximum-pool-size=1", "spring.jpa.hibernate.ddl-auto=validate" })
class TenancyTests {

	@SpringBootConfiguration
	@EnableAutoConfiguration
	@Import({ TenancyModule.class, TestcontainersConfiguration.class })
	static class TestApp {
	}

	static final UUID A = UUID.fromString("aaaaaaaa-0000-4000-8000-000000000001");

	static final UUID B = UUID.fromString("bbbbbbbb-0000-4000-8000-000000000002");

	@Autowired
	NoteRepository notes;

	@Autowired
	TransactionTemplate transaction;

	@PersistenceContext
	EntityManager entityManager;

	private static Jwt jwt() {
		return Jwt.withTokenValue("t").header("alg", "none").subject("user").build();
	}

	/** Runs the work in a transaction as the given authentication (null = anonymous). */
	private <T> T as(Authentication authentication, Supplier<T> work) {
		SecurityContextHolder.getContext().setAuthentication(authentication);
		try {
			return transaction.execute(status -> work.get());
		}
		finally {
			SecurityContextHolder.clearContext();
		}
	}

	private <T> T asTenant(UUID tenant, Supplier<T> work) {
		return as(new KeycloakAuthentication(jwt(), List.of(), "user", tenant), work);
	}

	private List<String> texts() {
		return notes.findAll().stream().map(Note::getText).sorted().toList();
	}

	@SuppressWarnings("unchecked")
	private List<String> nativeTexts() {
		return entityManager.createNativeQuery("select text from tenancy_test.note order by text").getResultList();
	}

	@AfterEach
	void cleanUp() {
		asTenant(A, () -> { notes.deleteAll(); return null; });
		asTenant(B, () -> { notes.deleteAll(); return null; });
	}

	@Test
	void runsAsARoleThatRowLevelSecurityAppliesTo() {
		// Superusers, table owners and BYPASSRLS roles skip RLS: every other test here would prove nothing.
		Object[] role = asTenant(A, () -> (Object[]) entityManager.createNativeQuery(
				"select current_user::text, rolsuper, rolbypassrls from pg_roles where rolname = current_user")
				.getSingleResult());
		Number owned = asTenant(A, () -> (Number) entityManager.createNativeQuery(
				"select count(*) from pg_tables where tableowner = current_user").getSingleResult());

		assertThat(role).containsExactly("app_runtime", false, false);
		assertThat(owned.intValue()).isZero();
	}

	@Test
	void eachTenantSeesOnlyItsOwnRows() {
		asTenant(A, () -> notes.save(new Note("a1")));
		asTenant(B, () -> notes.save(new Note("b1")));

		assertThat(asTenant(A, this::texts)).containsExactly("a1");
		assertThat(asTenant(B, this::texts)).containsExactly("b1");
		assertThat(asTenant(A, () -> notes.findAll().getFirst().getTenantId())).isEqualTo(A);
```

```java
package com.example.tenancy;

import java.util.UUID;

import org.hibernate.context.spi.CurrentTenantIdentifierResolver;
import org.springframework.security.core.context.SecurityContextHolder;

import com.example.security.KeycloakAuthentication;

/**
 * Hibernate's current tenant: the one resolved for the request's {@link KeycloakAuthentication}. Anything else
 * (no authentication, no tenant, another authentication type) is {@link #ROOT}: Hibernate does not filter, which
 * keeps global tables such as {@code iam.*} readable, and {@link RlsConnectionProvider} sets no tenant on the
 * connection, so row-level security shows no tenant rows and rejects tenant writes.
 */
public final class JwtTenantIdentifierResolver implements CurrentTenantIdentifierResolver<UUID> {

	public static final UUID ROOT = new UUID(0L, 0L);

	@Override
	public UUID resolveCurrentTenantIdentifier() {
		return SecurityContextHolder.getContext().getAuthentication() instanceof KeycloakAuthentication authentication
				? authentication.getTenantId().orElse(ROOT)
				: ROOT;
	}

	@Override
	public boolean validateExistingCurrentSessions() {
		return false;
	}

	@Override
	public boolean isRoot(UUID tenantId) {
		return ROOT.equals(tenantId);
	}

}
```

`RlsConnectionProvider.java`:

```java
package com.example.tenancy;

import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.SQLException;
import java.util.UUID;

import javax.sql.DataSource;

import com.zaxxer.hikari.HikariDataSource;
import org.hibernate.engine.jdbc.connections.spi.MultiTenantConnectionProvider;

/**
 * Hands Hibernate pooled connections with the tenant set as {@code app.tenant_id}, which the row-level security
 * policies compare against. The setting is cleared before a connection goes back to the pool; a connection that
 * cannot be cleared is evicted, because the next borrower would otherwise act as this tenant.
 */
final class RlsConnectionProvider implements MultiTenantConnectionProvider<UUID> {

	private final DataSource dataSource;

	RlsConnectionProvider(DataSource dataSource) {
		this.dataSource = dataSource;
	}

	@Override
	public Connection getAnyConnection() throws SQLException {
		return dataSource.getConnection();
	}

	@Override
	public void releaseAnyConnection(Connection connection) throws SQLException {
		connection.close();
	}

	@Override
	public Connection getConnection(UUID tenantId) throws SQLException {
		Connection connection = getAnyConnection();
		if (!JwtTenantIdentifierResolver.ROOT.equals(tenantId)) {
			try {
				setTenant(connection, tenantId.toString());
			}
			catch (SQLException ex) {
				discard(connection);
				throw ex;
			}
		}
		return connection;
	}

	@Override
	public void releaseConnection(UUID tenantId, Connection connection) throws SQLException {
		try {
			setTenant(connection, "");
		}
		catch (SQLException ex) {
			discard(connection);
			throw ex;
		}
		connection.close();
	}

	@Override
	public boolean supportsAggressiveRelease() {
		return false;
	}

	@Override
	public boolean isUnwrappableAs(Class<?> unwrapType) {
		return unwrapType.isInstance(this);
	}

	@Override
	public <T> T unwrap(Class<T> unwrapType) {
		return unwrapType.cast(this);
	}

	private static void setTenant(Connection connection, String tenantId) throws SQLException {
		// Session-level (false): Hibernate may borrow the connection before the transaction begins.
		try (PreparedStatement statement = connection.prepareStatement("select set_config('app.tenant_id', ?, false)")) {
			statement.setString(1, tenantId);
			statement.execute();
		}
	}

	private void discard(Connection connection) throws SQLException {
		if (dataSource.isWrapperFor(HikariDataSource.class)) {
			dataSource.unwrap(HikariDataSource.class).evictConnection(connection);
		}
		else {
			connection.close();
		}
	}

}
```

- [ ] **Step 2: CLAUDE.md**

Under "Decisions that are deliberate", add:
- **Tenants are Keycloak organizations; isolation is `tenant_id` + Hibernate `@TenantId` + Postgres RLS.** The tenant
  comes only from the token's `organization` claim (aliases), resolved once by `KeycloakJwtAuthenticationConverter`
  through `TenantDirectory` (implemented by `iam`) and carried on `KeycloakAuthentication`. `backend/tenancy` sets it
  on Hibernate and on each pooled connection (`app.tenant_id`). One user = one tenant.
- **The API connects as `app_runtime`** (no superuser, owns nothing), Flyway as `app`; RLS does not apply to owners
  and superusers.

Under "Gotchas", add:
- Every tenant table needs: `tenant_id UUID NOT NULL`, `@TenantId` on the entity, `ENABLE ROW LEVEL SECURITY` with a
  policy using `nullif(current_setting('app.tenant_id', true), '')::uuid` in both `USING` and `WITH CHECK`, grants to
  `app_runtime` in the module's migration, and indexes/uniques starting with `tenant_id`.
- Flyway versions are global across module folders: two modules must not use the same `V<date>_<n>` on the same day.
- Never declare `clientScopes` in the realm file: Keycloak then skips its built-in scopes and tokens lose `sub` and
  `preferred_username`. The `zk-shell` client needs the `organization` scope, or every user has no tenant.
- Code running outside a request (future scheduled jobs, `@Async`) has no `KeycloakAuthentication` and therefore sees
  no tenant data; it must set an authentication for the tenant it works for.
- Backend tests run the application as `app_runtime` (`app-runtime-role.sql` + `TestcontainersConfiguration` with a
  `DynamicPropertyRegistrar`); never use `@ServiceConnection` there, it would connect as the superuser and every RLS
  test would pass for the wrong reason.
